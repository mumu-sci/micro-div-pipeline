# 01 · 科学问题 → 模块 → 方法（含推荐规则）

> 用户以**科学问题**为入口，而不是直接点模块。本表把常见问题映射到**推荐模块组合**，
> 并给出每个模块内部的方法选项与推荐。**每一行都要带理由**，不要只罗列。

---

## 2. 模块 → 方法选项与推荐

### `10_composition` 物种组成
| 选项 | 可选项 | 推荐 | 理由 |
|---|---|---|---|
| 分类层级 | 任意 `tax_ranks` | 门（总览）+ 属（细节）各出一张 | 门看大格局，属看具体响应类群 |
| Top-N | 5–30 | 15（属） | 再多图例会溢出（本包已用 `md_guide_flex` 防裁切） |
| 核心/稀有阈值 | 丰度 × 出现率双阈值 | 丰度 0.1%、出现率 10% | 与常见文献口径一致 |
| 输入口径 | 未抽平 / 抽平 | **未抽平** | 抽平会压缩优势类群 |

### `11_alpha` α 多样性
| 选项 | 可选项 | 推荐 | 理由 |
|---|---|---|---|
| 指数 | Observed / Chao1 / ACE / Shannon / Simpson / Pielou / PD | **Observed + Shannon + Pielou + PD** | 覆盖丰富度 / 均匀度 / 谱系三个维度；Chao1/ACE 深度不够时虚高 |
| 组间检验 | anova_tukey / kruskal_dunn / lmm / none | 先看 `01` 的正态性与方差齐性 | 方法选错直接影响 P |
| 多重校正 | BH / holm / fdr / bonferroni | BH | 生态学惯例 |
| 显著性标注 | auto / letters / brackets / none | **>4 组必须字母** | 括号会挤成一团 |
| 稀释曲线 | vegan / inext / both | vegan | 够用且快 |

### `13_distances` 距离矩阵
| 选项 | 推荐 | 理由 |
|---|---|---|
| Bray-Curtis | **必选** | 丰度型 Beta 多样性的默认口径 |
| Jaccard（binary） | **建议** | 有无型；与 Bray 对比可判断"丰度 vs 有无"的贡献 |
| UniFrac / wUniFrac | 有树时建议 | 系统发育口径；无树自动跳过 |

### `14_ordination` 排序
| 选项 | 推荐 | 理由 |
|---|---|---|
| PCoA | **默认** | 与 PERMANOVA 同源（都基于距离矩阵），可报轴解释率 |
| NMDS | 稳健性补充 | 非线性更好但无解释率、需报 stress |
| 95% 椭圆 | 每组 n ≥ 4 才画 | 样本太少椭圆不可靠 |
| 双标图显示 | 样方点 / 变量点 / 两者 | **样方多时只出样方点**（不许代选） |

### `15_beta_tests` 多元差异检验
| 选项 | 推荐 | 理由 |
|---|---|---|
| PERMANOVA | **必选**，用 `by="terms"` | 本机 `by="margin"` 只返回末项（已知 bug） |
| ANOSIM | 建议 | 基于秩，与 PERMANOVA 互补 |
| PERMDISP | **必选** | 显著性可能来自离散度差异而非位置差异，审稿人会问 |
| 两两比较 | 水平 ≤ 6 时做 | 对数随水平数平方增长；每组 < `min_group_n` 记 NA |
| 置换次数 | 999 | 论文标准 |

### `16_beta_components` β 周转分解
| 选项 | 推荐 | 理由 |
|---|---|---|
| Sørensen 分解 | **默认** | 对丰度不敏感，适合高周转数据 |
| Bray 分解（balanced/gradient） | 建议作为敏感性 | 丰度型口径；与 Sørensen 结论一致才稳健 |

### `17_gamma_partition` α-β-γ 分区
| 选项 | 推荐 | 理由 |
|---|---|---|
| Hill 阶 | **q = 0, 1, 2 三档** | 审稿人常要求；只报一档会被质疑 |
| 稀释水平 t | **自动**（各组采样单元数中位数） | 手工剔除组会造成选择性报告 |
| 覆盖度 SC | **必须报** | 覆盖度低时 iNEXT 外推倍数大，不报会被质疑 |

### `20_phylo_prep` / `21_phylo_diversity` / `22_phylo_beta` 系统发育
| 选项 | 推荐 | 理由 |
|---|---|---|
| 生根 | midpoint（无外群时） | 多数 ASV 树无根 |
| PD | `picante::pd(include.root=FALSE)` | 与常见口径一致 |
| MPD/MNTD 零模型 | `ses.mpd/ses.mntd(null.model="taxa.labels", runs=999)` | 打乱物种身份、保留丰度结构 |
| NRI/NTI 阈值 | ±2 | 惯例 |
| 系统发育 β 子集 | `prev_min = 2` | 单例类群会让系统发育距离极不稳定 |

### `30_null_models` / `31_assembly_process` 群落组装
| 选项 | 推荐 | 理由 |
|---|---|---|
| βNTI 零模型 | `independentswap` × 999 | Stegen 框架标准 |
| RCbray | `permatfull(fixedmar="columns")` × 999 | 固定样本丰富度 |
| 判定阈值 | \|βNTI\|>2、\|RCbray\|>0.95 | 惯例；改它必须给理由 |
| 五过程 | Variable/Homogeneous selection、Dispersal limitation、Homogenizing dispersal、Drift | Stegen 2013 |
| 大样本 | 分块 + 并行 | RCbray 的 `n²×runs` 数组会爆内存 |

### `33_distance_decay` 距离衰减
| 选项 | 推荐 | 理由 |
|---|---|---|
| 相似性 | 1 − Bray | log 变换后才能线性拟合 |
| 距离 | 地理（Haversine）/ 环境（标准化欧氏）/ 群落 | 三口径对比能判断"空间 vs 环境"驱动 |
| 拟合 | `lm(log(Similarity) ~ log(Dist))` | 幂律衰减的标准形式 |
| 最少对数 | ≥ 10 | 更少则斜率不稳 |

### `34_variance_partition` 变差分解
| 选项 | 推荐 | 理由 |
|---|---|---|
| 分块 | 按科学假设（如 气候 / 土壤 / 空间） | 分块方式决定结论，必须事前定 |
| 转换 | Hellinger | 群落数据的标准预处理 |
| 显著性 | 偏 RDA + 999 置换 + Holm | 单块检验必须校正 |
| 注意 | 校正 R² 可能为负 | 负值要照实写，不能截断为 0 |

### `40_env_summary` 环境表征
| 选项 | 推荐 | 理由 |
|---|---|---|
| 相关方法 | Spearman | 环境变量常非正态 |
| 校正范围 | **上三角独立配对** | 对含重复的整矩阵校正会过度保守 |
| VIF 门限 | 10（宽松）/ 5（严格） | 共线变量会让模型系数不稳 |
| PCA log | 量纲差异大时 TRUE，**pH 豁免** | pH 本身是对数刻度 |
| PCA 双标图 | 只出样方点（默认） | 变量点会和样方点糊在一起 |

### `43_mantel_mrm` Mantel / MRM
| 选项 | 推荐 | 理由 |
|---|---|---|
| Mantel | 单变量对单变量 | 简单直观但**不控制协变量** |
| partial Mantel | 要控制第三变量时 | |
| MRM | 多变量回归距离矩阵 | 可同时纳入多个解释距离 |
| 置换层级 | **必须在表里写清**（对象级 n = 样本数，不是对数级） | 常见的审稿意见 |
| 饱和诊断 | **必做** | 距离有数学上限，接近上限时"无关系"是假象 |

### `50_lmm` 混合模型
| 选项 | 推荐 | 理由 |
|---|---|---|
| REML | FALSE | 便于似然比比较 |
| P 值方法 | Satterthwaite | 小样本更稳 |
| 稳健标准误 | 站点 < 10 时开 | 防 CI 过窄 |
| 非线性 | GAMM 的 edf > 1.1 才画曲线 | 否则会过拟合噪声 |
| 共线守卫 | 站点内唯一值 = 1 的变量自动降集 | 站点级变量与站点随机效应共线，系数不可唯一归因 |

### `52_sem` SEM
| 选项 | 推荐 | 理由 |
|---|---|---|
| 结构来源 | **用户声明的边表** | 自动探索结构不可接受 |
| d-separation | 必做 | Fisher's C 是 SEM 的证伪检验 |
| 路径 P 校正 | BH（并注明范围） | 同一模型内多路径 |
| 子模型 | `lm` 或 `lmer`（可混用） | 有重复采样时必须用 `lmer` |

### `53_sensitivity` 敏感性分析
| 选项 | 推荐 | 理由 |
|---|---|---|
| 剔除对象 | 特殊处理组 / 极端站点 / 离群点 | 审稿人一定会问"结论是不是被某几个样本驱动" |
| 对比展示 | 森林图并列 | 一眼看出哪个结论变脆 |

### `60_spatial_autocorr` 空间自相关
| 选项 | 推荐 | 理由 |
|---|---|---|
| 分析层级 | **auto** | 坐标重复时样本级自相关是伪重复 |
| 权重 | k-NN 反距离，k = max(3, min(n/4, 10)) | k 太大权重被稀释 |
| 残差 Moran's I | 建议做 | 扣掉环境效应后才能判断"剩余空间结构" |

### `70_response_pattern` / `71_response_linkage` 响应变量
| 选项 | 推荐 | 理由 |
|---|---|---|
| 因子格局 | 双因子交互箱线 + CLD | 看交互是否存在 |
| 与 α 的关联 | 单回归 + 偏回归 + LMM/GAMM | 单回归会被混杂因素污染 |
| 与排序轴的关联 | 只看第一轴 | 第二轴生物学含义通常不清 |
| 成对尺度 | MRM/Mantel + 站点对 bootstrap CI | 成对数据严重伪重复，普通回归的 P 值不可信 |
| 森林图 | 必出 | 多口径效应量并排，一眼看稳健性 |

## 3. 方法选择的通用原则（给"不懂怎么选"的用户）

1. **先看诊断再选方法**：正态性/方差齐性/样本量决定参数还是非参数；坐标是否重复决定层级。
2. **多口径并报**：同一个问题用两三种口径算，结论一致才写进论文。
3. **优先保守**：小样本、伪重复、多重比较场景一律选更保守的方法并校正。
4. **不许选择性报告**：不利的 P 值不能因为"换个口径就显著"而被隐去；口径变化写进表注。
5. **参数值要能追溯到论文**：置换次数、校正方法、阈值都要写进方法或表注。
